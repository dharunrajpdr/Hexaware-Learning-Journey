## ▶️ How to Run

1. Make sure Java JDK is installed on your system.
2. Open the folder containing the Java source file.
3. Compile the program:

   ```bash
   javac Main.java
   ```

4. Run the program:

   ```bash
   java Main
   ```

   Replace `Main` with the actual filename and class name when necessary.
